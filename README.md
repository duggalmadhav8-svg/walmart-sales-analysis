# 🛒 Walmart Sales Performance & Trend Analysis

An exploratory data analysis (EDA) project built in Python to evaluate retail store sales, uncover seasonal trends, and analyze the impact of holidays on store performance.

---

## 🚀 Project Overview
This project processes and analyzes multi-store retail data to uncover patterns in sales distribution, category performance, and seasonal fluctuations. By leveraging data aggregation and feature engineering, the analysis provides actionable business intelligence for retail optimization.

---

## 🛠️ Tools & Libraries Used
* **Python:** Core programming language.
* **Pandas & NumPy:** Data cleaning, manipulation, and feature engineering.
* **Matplotlib & Seaborn:** Data visualization and trend plotting.
* **Google Colab / Jupyter Notebook:** Development and execution environment.

---

## 📈 Key Analysis & Features
* **Store Sales Categorization:** Segmented stores based on performance tiers and volume output.
* **Feature Engineering:** Extracted temporal features (months, seasons, holiday indicators) to track time-series trends.
* **Holiday Impact Analysis:** Evaluated how promotional periods and holidays influence weekly sales spikes.
* **Visual Trends:** Generated distribution charts, correlation heatmaps, and seasonal comparison plots.
